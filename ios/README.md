# ParkGo iOS

The iOS 18 app uses SwiftUI and a small dependency-injected architecture. Open `ParkGo.xcodeproj` in Xcode 16+ and run the `ParkGo` scheme. Debug configuration enables the clearly labelled demo experience and points to `http://localhost:8000/api/v1`; production builds require HTTPS and disable parking actions while the configured provider is mock.
