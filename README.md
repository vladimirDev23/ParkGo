# ParkGo

ParkGo — production-oriented MVP iOS-приложения для городских парковок.

## Структура репозитория

- `backend/` — backend на FastAPI.
- `ios/` — iOS-приложение на SwiftUI.
- `docs/` — документация проекта.
- `infrastructure/` — локальная инфраструктура и Docker Compose.
- `.github/` — конфигурация GitHub Actions.

Проект находится на этапе первоначальной настройки.
